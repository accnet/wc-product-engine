# 09 — UI

## 1. Apps và style

V1 có storefront enhancements trong theme Woo và operations trong WP Admin, không app SaaS/Next.js riêng. Giữ WP admin design conventions, layout responsive desktop/mobile. UI tiếng Anh + translation hooks, docs tiếng Việt; giá hiển thị Woo currency precision/tax context, thời gian user/store timezone label rõ.

## 2. Catalog

Giữ shop/categories/attributes UI theme, query adapter phục vụ dữ liệu. Filters show current selections/counts theo mode advertised; page count đúng WP loop. Loading skeleton chỉ khi AJAX adapter; empty state “No products match these filters” + reset; error retry với preserved selection; unsupported native filter không silently ignore.

## 3. PDP variant selector

| State | Display | Action |
|---|---|---|
| Initial | Defaults + parent gallery/price range | Add to cart disabled nếu chưa exact |
| Partial | Selected values + allowed next values | Không tạo false combination |
| Resolving | Small loading/aria-busy; preserve labels | Abort/sequence stale response |
| Exact purchasable | Price/stock/image đúng variant | Populate WC variation_id + attributes |
| Exact unavailable | Variant exists + out-of-stock/reason | Add to cart disabled trừ certified backorder |
| None | “This combination is unavailable” | Reset/change selection |
| Ambiguous | “Selection cannot be resolved” | No purchase, operator report |
| Revision changed | Refresh allowed values/current data | Revalidate, không giữ stale hidden ID |
| Error | Retry, preserved selection | Browser price/stock không authoritative |

Dropdown baseline; optional swatches keyboard button/label rõ, color không sole signal. Reset về default, parent gallery restore. Screen-reader live region không spam request text; focus giữ selected control.

## 4. Gallery

Native classic zoom/lightbox/thumbs/swipe; selected variation primary + supported multi-image extension. Broken external image placeholder có alt; no HEAD on render; width/height tránh layout shift. Media editor drag reorder/featured/variant primary mapping, save atomically. File editing/crop unsupported báo rõ; không giả file local.

## 5. Import/export screens

Import wizard Upload →Format/profile→Mapping→Dry-run report→Commit job→Result/download report. Columns absent/blank clear policy show in mapping, external/download image mode explicit. Dry-run counts created/updated/skipped/errors/variant removals/loss fields; commit disabled nếu validation invalid/hash stale. Default merge, replace variations toggle + preview. Background job progress/checkpoint/rate/retry/cancel; cancel text “Completed products remain saved”.

Export choose format/profile/filters/fields, strict default; loss preview before allow lossy; machine/spreadsheet-safe profiles distinct. Jobs/results downloads private with expiry, error rows downloadable authorized. No filesystem paths/token URLs in UI.

## 6. Operations dashboard

Cards authority/cohort/source counts/index freshness/outbox/DLQ/mismatches. Cohort view manifest/version/plugin matrix/gate evidence timestamps. Buttons Validate/Backfill/Rebuild/Reconcile/Replay gated by status/caps. Cutover requires successful current gate + manifest same epoch; no “force bypass” button. Rollback preview current data/lag/barrier effects, action authorized within operator task scope.

## 7. WP product admin compatibility

Existing edit/quick/bulk/duplicate/attributes/variants lists work via adapters; user can see mode/capability warning unobtrusively, not core plumbing in storefront. Product errors field-level, version conflict reload diff, no silent overwrite. Variants paginated, no10k inline JSON. Unsupported product type stays legacy with indicator.

## 8. Permissions và UI states

Unauthorized button hidden hoặc disabled explanatory; server caps always enforce. Every list/editor has loading/empty/error/retry/forbidden/stale version, job cancellation/loading handled. Public visitor không see operations/source debug. Admin dangerous cleanup review counts/ref integrity/rollback implication and operator explicit command, không auto action on activate.
